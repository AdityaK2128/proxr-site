# ProXR website

The website for ProXR, the iPhone app that gives display glasses a screen of their own.

- `index.html`: the product page
- `support.html`: help and contact (the App Store's support URL)
- `privacy.html`: privacy policy (the App Store's privacy policy URL)
- `terms.html`: terms of use

Static HTML and CSS, served by GitHub Pages. Support: ak2128@proton.me
